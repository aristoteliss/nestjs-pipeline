Η έκδοση 0.2.1 περιλαμβάνει μόνο προσθήκες: καμία εξαγωγή, υπογραφή ή συμπεριφορά του 0.2.0 δεν αλλάζει, και κανένα εύρος peer dependencies δεν μεταβάλλεται.
Αναβαθμίστε τα δέκα παραπάνω πακέτα σε `^0.2.1` για να χρησιμοποιήσετε τα ακόλουθα.

## Span attributes από κάθε add-on <a id="span-attributes-from-every-add-on"></a>

Κάθε add-on δημοσιεύει την απόφασή του ως εγγραφή `context.items` και πλέον εξάγει έναν builder που τη μετατρέπει σε επίπεδα attributes (flat attributes), `{}` όταν το behavior δεν εκτελέστηκε και ποτέ ως κλειδί.
Το `AttributesBehavior` του `@nestjs-pipeline/opentelemetry` εκτελεί τους builders που επιλέγετε αφού ολοκληρωθεί η αλυσίδα και προσθέτει το αποτέλεσμα στα attributes που το `TraceBehavior` τοποθετεί στο span:

```typescript
import { buildCacheAttributes } from '@nestjs-pipeline/cache';
import { buildDeadLetterAttributes } from '@nestjs-pipeline/deadletter';
import { buildFeatureFlagAttributes } from '@nestjs-pipeline/feature-flags';
import { buildIdempotencyAttributes } from '@nestjs-pipeline/idempotency';
import {
  AttributesBehavior,
  MetricsBehavior,
  TraceBehavior,
} from '@nestjs-pipeline/opentelemetry';
import { buildRateLimitAttributes } from '@nestjs-pipeline/rate-limit';

PipelineModule.forRoot({
  globalBehaviors: {
    before: [
      TraceBehavior,
      MetricsBehavior,
      [AttributesBehavior, {
        factories: [
          buildFeatureFlagAttributes, // feature_flag.key, .enabled, .variant, .reason, .error_code
          buildCacheAttributes,       // cache.hit
          buildIdempotencyAttributes, // idempotency.replayed, .ownership_lost
          buildRateLimitAttributes,   // rate_limit.remaining_points
          buildDeadLetterAttributes,  // dead_letter.captured
        ],
      }],
    ],
  },
});
```

Οι builders αποτελούν απλά δεδομένα, όχι μόνο για τηλεμετρία. Τυλίξτε έναν για να μετονομάσετε ένα attribute, ή χρησιμοποιήστε τον ως metadata για audit, με το `audit()` δηλωμένο έξω από το behavior που περιγράφει:

```typescript
const cacheHit = (context: IPipelineContext) => {
  const { 'cache.hit': hit } = buildCacheAttributes(context);
  return hit === undefined ? {} : { 'app.cache_hit': hit };
};

@UsePipeline(
  audit({ action: 'order.create', metadata: buildIdempotencyAttributes }),
  idempotent({ keyFactory }),
)
```

## Έτοιμο σύνολο δικαιωμάτων (Permission Digest) <a id="a-ready-made-permission-digest"></a>

Το `@nestjs-pipeline/casl` εξάγει το `abilityDigest(context?)`: το SHA-256 των ενεργών κανόνων του καλούντος, με τις συνθήκες ήδη επιλυμένες έναντι του principal, ώστε οποιαδήποτε αλλαγή μπορεί να αλλάξει μια απόφαση να το αλλάζει επίσης. Χρησιμοποιήστε το ως το scope ενός κλειδιού cache με principal scope, και το `requireAbilityDigest`, το οποίο προκαλεί σφάλμα `MissingAbilityError` ελλείψει ability, ως scope επανάληψης idempotency (replay scope):

```typescript
import { abilityDigest, getCaslPrincipal, requireAbilityDigest } from '@nestjs-pipeline/casl';

const overviewKey = createPartitionedCacheKeyFactory({
  principal: (ctx) => getCaslPrincipal(ctx)?.id,
  scope: abilityDigest,
});

@UsePipeline(idempotent({ keyFactory, replayScopeFactory: requireAbilityDigest }))
```

Το `CaslAuthorizer.dependsOnEntity(action, subject)` ενημερώνει έναν handler ότι ένας κανόνας υπό συνθήκη αποφασίζει με βάση attributes της οντότητας, ώστε να διαβάσει την οντότητα εκ νέου (fresh) αντί από το cache:

```typescript
const refresh = this.authorizer.dependsOnEntity('read', 'User');
const user = await this.users.find(new GetUserQuery({ userId }, { refresh }));
```

## Tenant με τον σκοπό (purpose) πρώτο <a id="tenant-with-the-purpose-first"></a>

Το `@cqrs-ddd/core` προσθέτει το `requireTenant(purpose, source?)`. Επιστρέφει τον tenant από το `source`, ή από τον resolver που έχει δηλωθεί με το `setTenantResolver`, και προκαλεί `MissingTenantContextError` όταν δεν υπάρχει κανένας:

```typescript
import { requireTenant } from '@cqrs-ddd/core/application';

requireTenant('access token issuance');           // the current tenant
requireTenant('users.create idempotency key', ctx); // ctx.tenantId, else the current one
```

Το `requireTenantId(source, purpose)` εξακολουθεί να λειτουργεί και είναι deprecated: αντιστρέψτε τα ορίσματα και καλέστε το `requireTenant`.
