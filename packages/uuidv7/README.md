# @cqrs-ddd/uuidv7

Generates and validates UUID version 7 identifiers as defined by
[RFC 9562](https://www.rfc-editor.org/rfc/rfc9562). It has no runtime dependencies and
no framework: it uses Node's built-in `crypto.randomBytes()` only.

**Documentation:** [guide](https://aristoteliss.github.io/nestjs-pipeline/packages/cqrs-ddd/uuidv7/) · [API reference](https://aristoteliss.github.io/nestjs-pipeline/api/cqrs-ddd/uuidv7/) · [all packages](https://aristoteliss.github.io/nestjs-pipeline/)

## Installation

```bash
npm install @cqrs-ddd/uuidv7
# or
pnpm add @cqrs-ddd/uuidv7
```

Requires Node.js 22.12 or later.

Published as an ES module; a CommonJS application loads it with `require()`. Coming from 0.3.x, see [Upgrading from 0.3.x](https://aristoteliss.github.io/nestjs-pipeline/upgrading/from-0-3/).
